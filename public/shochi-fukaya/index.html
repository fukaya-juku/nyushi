POINT

正智深谷高校合格への
ポイント

  1. 試験は国・数・英の3教科(各100点・50分・マークシート)。英語のリスニングはありません。マーク式に慣れておきましょう。
  2. 単願はグループ面接あり、併願は面接なし。単願は自己推薦書(学校指定の書式)も必要です。
  3. 特待生は単願だけが対象。単願で受けるかどうかは、個別相談で特待の見込みも聞いてから決めましょう。
  4. 併願は1月22日・23日・2月6日の3回。公立が第一志望なら、併願第1回を確実に押さえるのが基本です。

学習空間 深谷上柴教室から

正智深谷は、同じ学校の中で国立大志望から推薦中心の進学まで幅が広いのが特長です。どのコースで受けるかで必要な得点がちがうので、北辰テストの結果を持って早めに個別相談に行き、コースと受け方を決めましょう。

FEATURE

正智深谷高校の
校風と特色

校訓・教育目標校訓「選択」「専修」(浄土宗・法然上人の教えが建学の精神)

ここが特色

  • 所在地は深谷市上野台369番地。JR高崎線 深谷駅南口から徒歩約4分(400m)。無料スクールバスあり(熊谷・妻沼コース/寄居コース/森林公園コース)。
  • 普通科の中に、特別進学系(特別選抜・特別進学)と総合進学系(選抜進学・総合進学)の4コースがある。
  • 特別進学系は、模試を全員が受験(1年5回・2年6回・3年7回)し、個別指導の「志学塾」や自習室・進路室などで一般選抜に備える。
  • 総合進学系では、大学進学者の7割以上が指定校推薦で進学していると公式に記載(指定校推薦枠:157大学972名分)。面接・小論文・志望理由書の指導を独自テキストで行う。
  • 3年次に看護医療系コースがあり、医療系大学・医療系専門学校への進学に向けて数学・理科を重点的に学ぶ。
  • 付属校である埼玉工業大学への内部進学制度がある。
  • 浄土宗の宗門関係学校で、3年次には授業で茶道と華道を学ぶ。

学校生活

  • 制服の冬服は「墨黒(すみくろ)」のブレザー。女子のスカートは3柄(GRAY・CAMEL・GREEN)から選べ、通学バッグはリュック型かトート型を選べる。
  • 主な行事:9月の葵祭(文化祭)、10月の体育祭、7月の松川杯スポーツ大会、2月の修学旅行(2年)、1月の英語検定(準会場)。精霊会・成道会などの宗教行事もある。
  • トップアスリートクラブ(硬式野球・サッカー・男女バスケットボール・男女バレーボール・男女卓球)がある。
  • 女子バスケットボール部は全国高校総体に2年ぶり3回目の出場、関東大会には6年連続8回目の出場と公式ページに掲載(年度の記載なし)。
  • 女子卓球部は全国高校卓球大会で第5位(平成29年度)、全国高校選抜卓球大会の学校対抗に出場(令和4年度)。
  • サッカー部は全国高校総体の埼玉県代表予選で優勝し、全国大会出場と公式ページに掲載(年度の記載なし)。
